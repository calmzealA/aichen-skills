# AIChen Skills

这里收集「老陈聊AI」出品的 Skills。

## Skills

### aichen-decision

展示名：老陈帮我选

一个面向中文用户的选择拆解 Skill。适合处理上头、纠结、选择困难、怕后悔、日常加班几点回家、要不要继续干等问题。

使用示例：

```text
老陈帮我选：今天还在加班，几点回家？我还有两个任务没做完，但已经很累了。
```

目录：

```text
skills/aichen-decision/
  SKILL.md
  agents/openai.yaml
```

### aichen-explain

展示名：老陈讲明白

一个面向中文用户的概念解释 Skill。适合把 AI 术语、科技热点、商业概念、复杂新闻和用户粘贴的长文内容，用人话讲明白。

使用示例：

```text
老陈讲明白：MCP 到底是什么？用人话讲讲它和普通人有什么关系。
```

目录：

```text
skills/aichen-explain/
  SKILL.md
  agents/openai.yaml
```
